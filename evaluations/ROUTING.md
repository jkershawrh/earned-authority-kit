# Context-conditioned deterministic agent selection

This development comparison asks whether retaining outcomes by requested context improves agent selection. Two actual Python nano-agents scan the same nine-record catalog in opposite directions. Both comparators update from retained verified outcomes and apply the same current qualification and exact-resource authority checks. The pooled-outcome policy ranks live-eligible agents by mean catalog reads across contexts; the contextual-outcome policy ranks them within the requested context. Stable candidate-ID ordering breaks ties. Candidate direction is counterbalanced five/five across the ten declared seeds.

The opposing profile places requested records near opposite ends in alternating contexts. The homogeneous control places them near the same end in both contexts. These are constructed cases from one procedure/context ancestry. Forty sequences contain 320 assigned queries. Queries within a sequence are dependent; seeds are not independent population samples.

Each arm begins with the same twelve support attempts per sequence: two candidates, two contexts, three observations each. Support indices 100–105 differ from scored indices 0–7 and have different catalog/model values, but share keys, positional layouts and the same generator ancestry. This is development separation, not an unseen holdout. Later histories reflect each policy's own actions. Neither selector receives the current target, catalog, private grade or future outcomes.

The host registers each task before execution. A closure-held meter records actual catalog accesses; an independent trace check validates direction, count and returned model. Signed fixture job/work receipts bind the task, observation and work. A query is independently graded against persisted state and sealed before its cost becomes selectable evidence. Publication must preserve prior observations, costs, jobs, work and seals. The report consumer reconstructs eligibility and selection from signed observations, checks retained-state continuity and exact assignments, and recomputes outcomes and metrics. Missing, altered or incomplete evidence fails the engineering gate.

These are local fixture receipts, not canonical ledger attestations. Signatures bind records to report-carried keys; trustworthy source and artifact provenance remains necessary. The meter prevents ordinary attribute rewriting but does not isolate hostile Python reflection or compromised host/key owners. Grading and signing share a trusted process. The deadline is a scoring limit, not a hung-call watchdog.

Read counts measure nano-agent catalog accesses. Support reads and query reads are reported separately and combined; router, checker, signing and runtime overhead are excluded. Operator effort, monetary cost and instrumented LLM accounting remain unmeasured. No end-to-end speed or savings claim follows from these counts.

Current executable evidence: [routing report](../reports/edd-routing-002.json), [frozen development plan](routing-plan.json), [independent review](../evidence/edd-routing-review.md). The dedicated suite has 114 passing tests; the independent review has 42 passing probes. Initial and intermediate RED reports and regression logs remain preserved. The unchanged 514-test component baseline and earlier 300-episode/140-query scoped controls are separate evidence sets.

The next value gate requires a representative real workload, strong domain-specific baselines, a meaningful-effect and risk threshold, independently frozen holdout families and an actual operator comparison. Business, confirmatory, external reproduction, Red Hat deployment and robotics acceptance remain AMBER.

## Recorded development result

Both policies completed 160/160 assigned queries with zero observed unauthorized commits. The pooled policy used 660 query catalog reads; the contextual policy used 240. Each performed 1200 support reads. Including support, measured catalog accesses were 1860 and 1440, respectively. The homogeneous control tied at 120 query reads per policy; the opposing profile accounted for the difference. This establishes the contrast on these constructed fixtures only.
